# 基于多传感器与神经网络融合的智能鱼缸生态监控与自主运维系统

本项目基于 **ESP32-S3** 主控，集成 7 种传感器（pH、TDS、浊度、温度、水位、光照、CO2）和 7 路执行器（加热、水泵、加水泵、CO2 电磁阀、喂食器、水草灯、紫外灯），实现水质实时监测、自动控制（温控、补水、灯光、CO2、紫外灯）、远程监控（MQTT + 手机 App）和本地 LSTM 水质判断（TinyML 边缘推理），目标是打造一个低门槛、全自动、可远程交互的智能鱼缸系统。

## 硬件 IO 表

| 设备 | 引脚/地址 | 接口 | 说明 |
|------|----------|------|------|
| PCF8563 时钟 | GPIO8(SDA) / GPIO9(SCL) | I2C | 提供实时时间 |
| SGP30 CO2/TVOC | GPIO8(SDA) / GPIO9(SCL) | I2C | 检测空气中 CO2 |
| SD 卡 | GPIO10(CS) / GPIO12(SCK) / GPIO11(MISO) / GPIO13(MOSI) | SPI | 数据存储 |
| DS18B20 温度 | GPIO4 | OneWire | 水温检测 |
| 水位 | GPIO5 | ADC | 水位百分比 |
| 加热丝 | GPIO6 | GPIO 输出 | 高电平启动 |
| 水泵 | GPIO7 | GPIO 输出 | 循环水泵/主过滤泵，高电平启动 |
| 浊度计 | GPIO3 | ADC | 浊度检测 |
| TDS | GPIO2 | ADC | 总溶解固体 |
| pH | GPIO1 | ADC | 模拟输入 |
| 光照传感 | GPIO14 | ADC | 光照强度 |
| 喂食器 | GPIO15 | PWM 舵机 | 0-180°，喂食 120° |
| 水草灯 | GPIO16 | PWM 调光 | 0-100% 亮度 |
| 加水泵 | GPIO17 | GPIO 输出 | 自动补水泵，高电平启动 |
| CO2 电磁阀 | GPIO18 | GPIO 输出 | 高电平启动 |
| ASRPRO 语音 | GPIO19(RX) / GPIO20(TX) | UART | 语音控制（交叉接线） |
| 紫外灯 | GPIO47 | GPIO 输出 | 高电平启动，支持定时消杀 |

## 核心实现方式

### 1. 数据采集

- **I2C 总线**：读取 PCF8563 时间、SGP30 CO2
- **SPI 总线**：SD 卡读写
- **OneWire 总线**：DS18B20 水温
- **ADC**：水位、浊度、光照、TDS、pH

### 2. 自动控制

- **温度**：滞回控制（22-30℃），加热器自动启停
- **水位**：低于阈值自动补水，到达上限停止
- **灯光**：定时开关（8:00-18:00），亮度可调
- **CO2**：随灯光同步开关
- **喂食**：定时触发（8:00 / 17:30），舵机转 120° 后复位
- **紫外灯**：独立 GPIO 控制，支持定时开关

### 3. 数据记录与远程

- **本地**：传感器数据写入 SD 卡（CSV 格式）
- **远程**：ESP32 通过 WiFi + MQTT 上传数据至云端，手机 App 订阅查看

### 4. AI 水质判断

- **输入特征**：温度、pH、TDS、浊度、光照、CO2、水位、运行时长、小时、星期
- **模型**：LSTM（24 小时时间窗口）
- **部署**：TensorFlow Lite Micro 在 ESP32-S3 上本地推理，不依赖云端

### 5. 语音控制

- **模块**：ASRPRO 离线语音识别
- **指令集**：开/关灯光、水泵、加热、CO2、紫外灯、喂食、查询温度/pH 等
- **通信**：UART（9600，TX→GPIO19，RX→GPIO20）

## 当前代码对应的关键控制关系

- `pump.c`：循环水泵，`GPIO7`
- `water_pump.c`：加水泵，`GPIO17`
- `uv_lamp.c`：紫外灯，`GPIO47`
- `water_control.c`：低水位自动补水逻辑
- `main.c`：定时喂食、灯光、紫外灯调度，以及语音控制入口
